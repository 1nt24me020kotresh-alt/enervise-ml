# EnerVise — AI-Powered CNC Energy Optimization

Live App: https://enervise-ml.streamlit.app

## What This Is
EnerVise uses machine learning to predict and optimize 
energy consumption in CNC machining processes.

## Results
- Best Model: Decision Tree Regressor
- R² Score: 0.9724
- Energy Reduction: 5.21%
- Cost Saved: ₹31,885 per machine per year
- CO₂ Reduced: 3,076 kg per machine per year

## Dataset
UC Michigan CNC Mill Tool Wear Dataset
18 experiments, 17,520 active cutting samples
